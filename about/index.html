About the project

A drum kit in your pocket

Mega Drum is a mobile drum experience by Oliveira Labs, built for practice, creativity, and playing anywhere.

Why this catalog exists

The public website makes kits easier to discover, share, and revisit. Each page represents a kit already available in the app; the sounds themselves remain part of the mobile experience.

Built from the official catalog

Kit names, identifiers, and covers come from the same read-only catalog used by Mega Drum. The website does not write back to production data.
